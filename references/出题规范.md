# 出题规范

## 一、考点：写成一个动作

| 不要这样写 | 改成这样写 |
|---|---|
| 掌握条件概率 | 看到“已知……”，先把条件事件定为分母，再从缩小后的样本空间数结果 |
| 理解贡献毛益 | 只扣单位变动成本、不扣固定成本，按同一单位相减 |
| 了解全概率公式 | 把结果事件按来源拆成互斥的几支，各支概率相加 |

判断标准：这句话能不能对应一道题的具体一步？不能就是名词，不是考点。

## 二、每题只考一个动作

- 主考点放 `topics` 第一个，次要考点最多再挂一个。
- 一题串三个知识点，学生做错时你说不清他错在哪，评分点也没法分步给分。
- 题干给全数据：单位、精度、是否放回、是否独立，这些条件漏一个就不是“难”，是“没法做”。

## 三、先写答案，再检查题干

顺序不能反。写完满分答案后逐项检查：

1. 题干信息是否足够推出答案？（缺条件 → 补）
2. 干扰项是否“错得有道理”？（凑数的选项删掉，换成常见误算）
3. 题目是否只有一个正确解？（多解要在题干里限定）
4. 题干里有没有把答案或解题步骤写进去？

## 四、按学科选考法

**数理类**：计算、推导、判断反例、给错解让学生找错。
- 数值题必须自己复算一遍，并写出中间结果（`answer` 里带中间值，教师版才有用）。
- 评分点要能对应“错在哪一步就扣哪几分”。

**概念类**：比较两种解释、辨析错误说法、分析案例、给一段材料判断适用哪条规则。
- 辨析题的错误选项要写成学生真正会犯的错，而不是明显荒谬的话。
- 论述题的 `rubric` 要给出可接受的不同论证路径，而不是只认一个标准答案。

**计算+概念混合**：前半问算、后半问解释为什么（这种题最能区分“会套公式”和“真懂”）。

## 五、难度与时长

- **基础巩固**：每题集中练一个动作，条件直接给出。可以要求辨认定义、代入公式或完成一个典型步骤。
- **标准模拟（默认）**：把知识点放进新情境，让学生自己选方法。六题卷可从一两道基础题起步，至少安排一道要求解释选择依据或串联步骤的题。按章节实际内容调整。
- **提高挑战**：让主要题目要求反推条件、比较策略、构造反例或把本章两个知识点用在一起。学生应能说出多做了哪一步判断。避免仅把数字换大、题干写长或借用未学章节。
- 学生给出更具体的要求时优先满足，例如“只提高计算题，选择题基础一点”。有同课程往年卷可参照其思考步骤；没有往年卷就用上述教学口径。时间、题量、总分沿用学生的要求。
- 经验换算：1 分 ≈ 1 分钟。20 分的卷子给 20 分钟，低于 0.8 分钟/分组卷器会给黄条。
- 选择题 2 分/题是常态；计算题 6 分/题适合 20 分钟的小卷。

## 六、教材出处怎么写

- `quote` 必须**逐字摘抄**，从定义、公式或例题的原句里取，长度一句话以内。
- 有 PDF 页码写 `page`；只有文字/行号写 `line`。
- 引文的作用是让人 3 秒内翻到原件核对“这段原文是否真的支撑这道题”。所以引文要选**能支撑结论的那一句**，不是随便一句提到关键词的话。
- 没有教材依据时，`source` 写 `"none"`，并在回答里明确告诉用户“本卷没有教材依据，出处无法核对”。**编页码比没有页码危险得多。**

## 七、参照往年原卷时

1. 看原卷封面：课程、学期、考试类型（期中/期末/补考）。
2. 提取考法：老师要求学生完成什么动作（是记公式、还是判断适用条件、还是比较方案）。
3. 换情境，并改变**至少一项实质要求**：正向计算改成判断分母、单一方案改成比较方案、算结果改成解释原因。
4. 在回答里说清借鉴了哪一题、借鉴了什么；明确是“样卷/模拟卷”的，不能当成已举行考试的证据。
5. 没有真题证据时，不要写“老师常考”“往年考过”。

## 八、交付前最后一遍

| 检查 | 通过标准 |
|---|---|
| 分值闭合 | 各题之和 = 总分；每题 rubric 之和 = 题分 |
| 考点覆盖 | 每个考点至少一题，没有列了不用的 |
| 泄题 | 题干没有答案、没有解题步骤 |
| 选择项 | 4 个选项，key 在选项里，干扰项都“错得有道理” |
| 引文 | 每条都有 quote + page/line，且能支撑该题 |
| 数值 | 每题都独立算过，中间结果与答案一致 |
| 公式 | 只用允许的命令，不用矩阵/多行环境 |
