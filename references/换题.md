# 指定题的换题格式

整份新卷沿用题库格式。局部改题时，返回一个 JSON 对象，含原卷名 `title`、原课程 `course` 和数组 `replacements`。每个元素含原题 `id`、完整原题干 `before`、以及 `changes`。原题没有自带 ID 时，按原 JSON 数组顺序从 q1 起补 ID，然后映射到排版后的题号。

`changes` 必须给出新的 `ask`、`answer`、`rubric`、`trap`。选择题还需给出全部 `options` 和 `key`；原题含等价答案时更新 `accept`。题型、考点、分值和总分由原卷保留。分步评分点之和须等于原题分值。每个指定 ID 恰好出现一次；原题干和 JSON 实际内容一致，含原公式标记。

示例结构（文字和编号须换成本次试卷的实际内容）：

```json
{"title":"原卷名","course":"原课程","replacements":[{"id":"q5","before":"原题干","changes":{"ask":"新的计算题","answer":"计算与结论","rubric":[{"points":6,"for":"对应的完整解题步骤"}],"trap":"容易误用的条件"}}]}
```
