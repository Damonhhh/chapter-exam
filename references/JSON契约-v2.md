# JSON 契约 v2

组卷器只认这一份结构。字段名一个都不能改；多写的字段会被忽略，缺字段会报错或降级。

## 顶层

```json
{
  "schema": "kaoqian/v2",
  "meta": { ... },
  "sources": { "b": { ... } },
  "blueprint": [ ... ],
  "topics": [ ... ],
  "questions": [ ... ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema` | 建议 | 固定 `"kaoqian/v2"`；缺了也能读 |
| `meta` | 是 | 卷面信息 |
| `sources` | 有引用时必填 | 教材/往年卷/答案的来源，key 自定义 |
| `blueprint` | 建议 | 题型配比；缺了按题目实际顺序分组 |
| `topics` | 是 | 考点表 |
| `questions` | 是 | 题目 |

## meta

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 卷名，必填。如 `"第 3 章 条件概率与事件的独立性"` |
| `course` | string | 课程与用途。如 `"概率论与数理统计 · 期中练习"` |
| `minutes` | int | 建议时长。缺了卷头不显示时长，并给黄条 |
| `total` | int | 全卷总分，**必须等于各题 points 之和**；缺了按实际合计显示并给黄条 |
| `difficulty` | string | 整卷选用的难度档位。旧卷可省略，只换指定题时保留整卷原档。 |
| `cover` | string[] | 卷头填空项，默认 `["姓名","学号","班级"]` |

## sources

```json
"b": { "kind": "book", "title": "概率论与数理统计（第 3 章）", "file": "概率论第3章.pdf" }
```

| 字段 | 说明 |
|---|---|
| `kind` | `book`（教材）/ `exam`（往年原卷）/ `solution`（官方答案） |
| `title` | 卷面显示的材料名 |
| `file` | 文件名，仅作标注；组卷器不读文件 |
| `url` | 可选，公开原件链接 |

## topics

```json
{
  "id": "cond",
  "name": "条件概率的分母",
  "level": "应用",
  "skill": "看到“已知……”，先把条件事件定为分母，再从缩小后的样本空间数结果。",
  "ref": { "source": "b", "page": 57, "quote": "它作分母，不作分子" }
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一，题目用它对上考点 |
| `name` | 考点名，写成一个动作，不写“掌握 XX” |
| `level` | `记忆` / `理解` / `应用` / `分析`，进细目表 |
| `skill` | 一句话说清“做对这一步要做什么”，教师版会印出来 |
| `ref.source` | 指向 `sources` 的 key；没有教材依据写 `"none"` |
| `ref.page` | PDF 页码（正整数） |
| `ref.line` | 文本行号（正整数）。与 `page` 至少给一个 |
| `ref.quote` | **逐字摘抄**的原文，用于人工核对；空着直接报错 |

> 兼容旧格式：`ref.at` 会被当成 `page` 读。因此老版本的题组 JSON 也能直接载入。

## blueprint

```json
{ "type": "选择题", "count": 4, "points": 2, "level": "理解" }
```

`type` 只能是：`选择题` `填空题` `判断题` `计算题` `简答题` `论述题` `证明题` `解答题`。
组卷器用它决定**题型分组顺序**和组标题，并检查实际题量/分值是否与声明一致（不一致只是黄条，不拦截）。

短写会自动归一：`选择`→`选择题`、`计算`→`计算题`、`简答`→`简答题`、`判断`→`判断题`、`证明`→`证明题`、`填空`→`填空题`、`论述`→`论述题`。

## questions

```json
{
  "id": "q1",
  "type": "选择题",
  "ask": "设 $P(A)=0.5$，$P(B)=0.4$，$P(AB)=0.2$，则 $P(A|B)=$（　　）",
  "options": ["A. 0.2", "B. 0.4", "C. 0.5", "D. 0.8"],
  "key": "C",
  "topics": ["cond"],
  "points": 2,
  "answer": "C。$P(A|B)=\\frac{P(AB)}{P(B)}=0.5$。",
  "rubric": [{ "points": 2, "for": "选 C。" }],
  "trap": "把联合概率 0.2 当作答案会误选 A。"
}
```

| 字段 | 说明 |
|---|---|
| `type` | 与 blueprint 一致；缺省按 `解答题` 处理 |
| `ask` | 题干。不许含答案、不许写解题思路 |
| `options` | 选择题必填，以 `A. ` `B. ` `C. ` `D. ` 开头；非选择题写 `[]` |
| `key` | 选择题正确答案字母，A–D 之一 |
| `accept` | 填空题的等价答案数组（v2 判分用，v1 可省） |
| `topics` | 至少一个考点 id；主考点放第一个 |
| `points` | 正整数 |
| `answer` | 满分答案。可含 `$...$` |
| `rubric` | 分步评分点，**合计必须等于 points** |
| `rubric[].for` | 这一步给分的具体动作 |
| `trap` | 常见扣分原因，教师版印在“易错处” |

## 分批（长输出必用）

题目多时按批输出，每批仍是完整 JSON，多两个字段：

```json
{ "paperId": "期中-章节卷-01", "part": 1, "of": 3, "meta": {...}, "sources": {...}, "topics": [...], "questions": [ ...最多 5 题... ] }
```

每批带同一 paperId、卷名、课程、全卷总分和总批数。题目 id 跨批唯一且连续。第 1 批开始一份新卷，后续按顺序载入。只有批次到齐且分值核对通过才可打印。**没有 `part` 字段就是替换整份**。

## 组卷器会拦下（红条，必须改）

1. 各题 points 之和 ≠ `meta.total`
2. 某题 `rubric` 合计 ≠ 该题 points
3. 有考点一道题都没用上
4. 题干里整段出现了参考答案
5. 题干重复
6. 选择题 `options` 少于 2 个 / `key` 不在选项里
7. 考点引用了不存在的 `sources` key
8. `ref.quote` 为空，或 `page`、`line` 都没给
9. `ask`、`answer`、`rubric`、`points` 缺失

## 只会给黄条（能打，但建议改）

- 没有 `course` / `minutes` / `total`
- 考点没标 `level`
- 某题没写 `trap`
- 题干疑似把参考思路写进去了（连续 8 个汉字与答案重合）
- `blueprint` 的题量/分值与实际不符
- 平均每分钟分值配比异常（< 0.8 分钟/分）
- 考点没有教材出处（`source: "none"`）
